# Secret Notes Pro 🔐

Современный REST API сервис для обмена защищенными временными заметками.

## 📝 Идея продукта
Сервис предназначен для безопасной передачи чувствительной информации. Пользователь создает зашифрованную заметку, которая доступна по уникальному UUID. После первого прочтения или истечения срока жизни (TTL), заметка безвозвратно удаляется.

## ✨ Функциональные возможности
- **Safe Create:** Создание заметки с опциональным паролем для доступа.
- **Burn on Read:** Автоматическое удаление записи после первого успешного GET-запроса.
- **Auto-Expiry:** Автоматическая очистка просроченных заметок (через Background Tasks).
- **RESTful API:** Полное соответствие спецификации OpenAPI.

## 🏗 Технологический стек и архитектура
Проект реализуется на базе монолитной архитектуры с четким разделением слоев (Domain/Services/API):

- **Framework:** Django 5.x + Django REST Framework (DRF).
- **Language:** Python 3.12+ (с использованием Type Hinting).
- **Database:** PostgreSQL (в Docker-контейнере) для хранения метаданных и зашифрованного контента.
- **Validation:** Использование Serializers для строгой проверки входных данных.
- **Security:** 
  - Хеширование паролей доступа (PBKDF2).
  - Интеграция статического анализа (Semgrep) в CI.
